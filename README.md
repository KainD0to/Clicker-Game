# Clicker-Game
# Игра-кликер с элементами Tower Defense и градостроительства

---
## Идеи для развития
<p>В мои планах создать не просто кликер, а гибрид жанров:</p>
<ul>
  <li>Кликер</li>
  <li>Tower Defens (TD)</li>
  <li>Градостроительный симулятор (или, возможно, ферма)</li>
</ul>

---
## Уникальная стилистика игры
<p>Общий стиль будет опираться на dark-fantasy, готический стиль</p>
<p>Графика будет брать элементы из классических dark-fantasy игр и графику игр на ранних Playstation (Cry of fear, Silent Hill, ResidentEvil)</p>


- Тёмная, мрачная цветовая гамма
- Низкополигональные модели / пиксельные текстуры
- Зернистость и пост-эффекты в духе PSX-хорроров
- Готическая архитектура и оккультная символика


---
## Технологии

| Технология | Назначение |
|------------|------------|
| **React** | UI, интерфейс |
| **Zustand** | Управление состоянием |
| **Vite** | Сборка |
| **Tauri** (план) | Упаковка в десктоп |
| **Steamworks.js** (план) | Интеграция со Steam |
